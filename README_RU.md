# DOODA SHOP 3.0

Адаптивный каталог с корзиной, оформлением заказов, учётом остатков, клиентской базой и защищённой админ-панелью.

## Быстрый запуск Windows

1. Установите Python 3.11 или новее.
2. Запустите `START_LOCAL.ps1` из PowerShell.
3. Откройте `http://127.0.0.1:5000`.
4. Админ-панель: `http://127.0.0.1:5000/admin`.

## Запуск на сервере

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python3 setup_admin.py
export DOODA_SECRET_KEY="$(python3 -c 'import secrets; print(secrets.token_hex(32))')"
python3 -m waitress --host=127.0.0.1 --port=25330 app:app
```

Публикуйте приложение только через HTTPS. Настройте reverse proxy/Cloudflare Tunnel на `127.0.0.1:25330`.

## Учётная запись администратора

- Создание или сброс: `python3 setup_admin.py`.
- Автоматический временный пароль: `python3 setup_admin.py --username admin --generate`.
- После первого входа панель попросит сменить временный пароль.
- Пароль хранится только как стойкий хеш в SQLite.
- Старые переменные `DOODA_ADMIN_USERNAME` и `DOODA_ADMIN_PASSWORD_HASH` поддерживаются для миграции.
- Для входа через Telegram задайте `DOODA_ADMIN_TELEGRAM_ID` и `TELEGRAM_BOT_TOKEN`.

## Что добавлено

- Кнопка входа в админ-панель в шапке и профиле.
- Учётные записи с логином и паролем, смена пароля, ограничение попыток входа и CSRF-защита.
- Обзор со статистикой товаров, публикаций, категорий, фото и остатков.
- Цены, старые цены, метки `NEW/HIT/SALE`, символы, цвет карточки и блок «Выбор DOODA».
- Фильтр наличия и сортировка каталога по цене/новизне.
- Быстрая публикация и скрытие товара, создание копии карточки.
- До шести фотографий на товар, галерея в подробном просмотре.
- Экспорт каталога в JSON для резервного копирования.
- Улучшенная мобильная адаптация, пустые состояния и кнопка «Поделиться».
- Автоматическая миграция существующей SQLite-базы без удаления карточек.

## Заказы и склад

- Корзина хранится в браузере покупателя.
- При оформлении заказ атомарно резервирует нужное количество товара.
- Новый заказ появляется в админке со статусом «В резерве».
- Кнопка «Продан» фиксирует продажу: зарезервированный остаток остаётся списанным.
- Кнопка «Отменить» возвращает всё количество заказа на склад.
- Повторно подтвердить или отменить уже обработанный заказ нельзя.
- Для каждого клиента сохраняются телефон, Telegram ID/username (если доступны), число заказов и суммы.

## Уведомления в Telegram

Создайте бота через `@BotFather`, добавьте на сервер две переменные и перезапустите приложение:

```bash
export TELEGRAM_BOT_TOKEN="токен_бота"
export DOODA_ORDER_CHAT_ID="ваш_chat_id"
```

Без этих переменных сайт продолжит принимать заказы, а уведомления будут доступны во вкладке «Заказы» админ-панели.

## Резервное копирование

Сохраняйте папку `data` целиком: база находится в `data/catalog.sqlite3`, изображения — в `data/uploads`. JSON-экспорт из панели содержит структуру каталога, но не сами файлы изображений.

## Важно

- Не публикуйте `data`, `.env` и `admin.env` в открытом репозитории.
- Задайте постоянный `DOODA_SECRET_KEY` на сервере, иначе сессии будут сбрасываться после перезапуска.
- Это каталог без корзины, оплаты и оформления заказов. Эти возможности требуют отдельной интеграции с платёжной системой и политикой обработки данных.
